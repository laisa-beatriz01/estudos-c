
# 🚗 Sistema de Estacionamento em C

Projeto desenvolvido em linguagem C com o objetivo de praticar conceitos fundamentais de programação por meio da criação de um sistema simples de gerenciamento de estacionamento.

## 🎯 Objetivo

Desenvolver um programa que permita controlar a ocupação de vagas, registrar entradas e saídas de veículos e calcular os valores a serem pagos.

## ⚙️ Funcionalidades planejadas

O sistema contará com um menu interativo com as seguintes opções:

- **Registrar entrada:** ocupar uma vaga e atualizar a quantidade de vagas disponíveis.
- **Registrar saída:** liberar uma vaga e calcular o valor do estacionamento.
- **Consultar vagas:** exibir a quantidade de vagas disponíveis.
- **Consultar faturamento:** apresentar o valor total arrecadado.
- **Relatório:** exibir informações sobre a situação do estacionamento.
- **Sair:** encerrar o programa.

## 📋 Regras do estacionamento

- Capacidade máxima de 20 vagas.
- Primeira hora: R$ 8,00.
- Horas adicionais: R$ 5,00 por hora.

## 🛠️ Conceitos de programação utilizados

- Variáveis e tipos de dados
- Funções
- Ponteiros
- Estruturas condicionais
- Estruturas de repetição
- Estrutura `switch`
- Passagem de parâmetros por referência

## 💻 Tecnologias utilizadas

- Linguagem C
- GCC
- Visual Studio Code
- Linux

## 🚀 Como executar

Após a conclusão do projeto, será possível compilá-lo utilizando o GCC:

```bash
gcc main.c -o estacionamento
./estacionamento
```
